# Screenshot capture list

Save these as PNG in this folder. Always **Serbia**. Desktop, ~16:9 (about 1600×900). Dark theme as the app is. Pause playback unless noted.

| File | What to capture |
|---|---|
| `hero-globe-serbia.png` | **World map → Globe**, heatmap **Total fertility rate**, Serbia in view, **both sidebars collapsed**, year strip visible. Full-bleed hero. |
| `pyramid-serbia.png` | **Pyramid**, Serbia, **both side panels open**, flag window on, stats bar, start year (fresh TFR year). |
| `pyramid-serbia-2100.png` | Same pyramid, scrub to **2100**. |
| `map-hover-serbia.png` | **World map** (flat Map, not Globe), **Total fertility rate**, hover Serbia so the mini-pyramid and metric chip show. Sidebars collapsed. |
| `triangle-serbia.png` | **Triangle**, Serbia under the crosshair, hub card visible, sidebars collapsed. |
| `graphs-serbia.png` | **Country data** panel open on Serbia: TFR / population / e0 charts with the dashed UN WPP Medium overlay on. |

Optional extras: `regions-tfr.png` (Regions view, TFR), `map-pins-serbia.png` (Serbia pin tag).

Use an OS screenshot (Win+Shift+S) for map, globe, triangle, and hover. In-app **Snapshot PNG** only captures the pyramid canvas or the triangle overlay, not the world map.
